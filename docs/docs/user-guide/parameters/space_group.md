# `_space_group`

EdSTAR stores space-group descriptors under `_space_group` using
Python-aligned item names. CIF import and report export use the
standard IUCr item names.

## `_space_group.name_h_m` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Ispace_group.name_H-M_alt.html "IUCr definition") { #space-group-name-h-m }

International Hermann-Mauguin space-group symbol.

## `_space_group.coord_system_code` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Ispace_group.IT_coordinate_system_code.html "IUCr definition") { #space-group-coord-system-code }

Setting code from International Tables for Crystallography.
