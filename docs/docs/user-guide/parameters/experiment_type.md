# `_experiment_type`

EdSTAR stores the experiment axes under `_experiment_type`. These values
select compatible experiment categories, calculators, peak profiles, and
data handling.

## `_experiment_type.sample_form` { #experiment-type-sample-form }

Sample form used by the experiment. Supported values include `powder`
and `single crystal`.

## `_experiment_type.beam_mode` { #experiment-type-beam-mode }

Beam mode used by the experiment. Supported values include
`constant wavelength` and `time-of-flight`.

## `_experiment_type.radiation_probe` { #experiment-type-radiation-probe }

Radiation probe used by the experiment. Supported values include
`neutron` and `x-ray`.

## `_experiment_type.scattering_type` { #experiment-type-scattering-type }

Scattering type used by the experiment. Supported values include `bragg`
and `total`.
