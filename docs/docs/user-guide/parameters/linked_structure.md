# `_linked_structure`

EdSTAR stores experiment-to-structure links under `_linked_structure`.
Powder report CIF maps these rows to `_pd_phase_block`.

## `_linked_structure.structure_id` { #linked-structure-structure-id }

Identifier of the structure linked to the experiment.

## `_linked_structure.scale` { #linked-structure-scale }

Scale factor for the linked structure in the experiment.
