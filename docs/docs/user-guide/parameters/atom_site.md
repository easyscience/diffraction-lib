# `_atom_site`

EdSTAR stores atom-site rows under `_atom_site`. EasyDiffraction names
the row identity `id`; CIF import and report export use the standard
`_atom_site.label` key.

## `_atom_site.id` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.label.html "IUCr definition") { #atom-site-id }

EasyDiffraction atom-site identifier. Imported from and exported to CIF
as `_atom_site.label`.

## `_atom_site.type_symbol` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.type_symbol.html "IUCr definition") { #atom-site-type-symbol }

Chemical element or species occupying this site.

## `_atom_site.fract_x` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.fract_x.html "IUCr definition") { #atom-site-fract-x }

Fractional coordinate along the _a_ cell axis.

## `_atom_site.fract_y` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.fract_y.html "IUCr definition") { #atom-site-fract-y }

Fractional coordinate along the _b_ cell axis.

## `_atom_site.fract_z` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.fract_z.html "IUCr definition") { #atom-site-fract-z }

Fractional coordinate along the _c_ cell axis.

## `_atom_site.occupancy` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.occupancy.html "IUCr definition") { #atom-site-occupancy }

Fraction of the atom type present at this site.

## `_atom_site.adp_type` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.ADP_type.html "IUCr definition") { #atom-site-adp-type }

Atomic displacement parameter type. EasyDiffraction currently supports
isotropic `Biso`.

## `_atom_site.adp_iso` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.B_iso_or_equiv.html "IUCr definition") { #atom-site-adp-iso }

Isotropic atomic displacement parameter in angstroms squared.

## `_atom_site.multiplicity` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.site_symmetry_multiplicity.html "IUCr definition") { #atom-site-multiplicity }

Multiplicity generated by the space-group symmetry for this site.

## `_atom_site.wyckoff_letter` [:material-open-in-new:](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.Wyckoff_symbol.html "IUCr definition") { #atom-site-wyckoff-letter }

Wyckoff letter for the site.
