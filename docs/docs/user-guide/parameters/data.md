# `_data`

EdSTAR stores measured and calculated pattern points under `_data`.
Report CIF maps diffraction data to the appropriate pdCIF categories.

## `_data.id` { #data-id }

Stable row identifier for a measured or calculated data point.

## `_data.two_theta` { #data-two-theta }

Two-theta diffraction angle for constant-wavelength powder data.

## `_data.time_of_flight` { #data-time-of-flight }

Measured time for time-of-flight neutron data.

## `_data.d_spacing` { #data-d-spacing }

d-spacing for a calculated or processed point.

## `_data.intensity_meas` { #data-intensity-meas }

Measured intensity.

## `_data.intensity_meas_su` { #data-intensity-meas-su }

Standard uncertainty of the measured intensity.

## `_data.intensity_calc` { #data-intensity-calc }

Calculated intensity.

## `_data.intensity_bkg` { #data-intensity-bkg }

Calculated background intensity.

## `_data.calc_status` { #data-calc-status }

Calculation or refinement status for the data point.

## `_data.r` { #data-r }

Radial distance for total-scattering data.

## `_data.g_r_meas` { #data-g-r-meas }

Measured pair distribution value.

## `_data.g_r_meas_su` { #data-g-r-meas-su }

Standard uncertainty of the measured pair distribution value.

## `_data.g_r_calc` { #data-g-r-calc }

Calculated pair distribution value.
