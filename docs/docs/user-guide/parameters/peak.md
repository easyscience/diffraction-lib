# `_peak`

EdSTAR stores peak-profile parameters under `_peak`. The active peak
profile is selected from the experiment:

```python
experiment.peak.type = 'pseudo-voigt'
```

## Constant-Wavelength Powder Profiles

### `_peak.broad_gauss_u` { #peak-broad-gauss-u }

Gaussian broadening coefficient _U_.

### `_peak.broad_gauss_v` { #peak-broad-gauss-v }

Gaussian broadening coefficient _V_.

### `_peak.broad_gauss_w` { #peak-broad-gauss-w }

Gaussian broadening coefficient _W_.

### `_peak.broad_lorentz_x` { #peak-broad-lorentz-x }

Lorentzian broadening coefficient _X_.

### `_peak.broad_lorentz_y` { #peak-broad-lorentz-y }

Lorentzian broadening coefficient _Y_.
